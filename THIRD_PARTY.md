# Upstream components and research materials

RelaySpec integrates separately obtained model checkpoints, drafter code,
datasets, and document styles. Their own terms continue to apply. No new
project-wide software license is assigned by this repository cleanup.

| Component | Upstream source |
|---|---|
| DFlash | https://github.com/z-lab/dflash |
| DeepSpec / EAGLE-3 | https://github.com/deepseek-ai/DeepSpec |
| Qwen checkpoints | https://huggingface.co/Qwen |
| Llama checkpoints | https://huggingface.co/meta-llama |
| NVIDIA Nemotron | https://huggingface.co/nvidia |
| ICLR 2027 style | https://iclr.cc/Conferences/2027/AuthorGuidelines |
| EvalPlus | https://github.com/evalplus/evalplus |

Pinned revisions and dataset sources are in configurations, manifests, and
[the source log](docs/research/relayspec-source-log.md). Manifests contain
research text from identified datasets. Model weights are not included.
Vendored LaTeX packages retain their embedded license notices.
